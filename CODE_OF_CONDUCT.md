# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, as its
Code of Conduct. The full text is published at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: we expect everyone participating in this project — issues,
pull requests, discussions, any channel — to behave with respect and
good faith. Personal attacks, harassment, and discrimination are not
welcome and will be addressed.

## Reporting

If you see or experience behavior that violates the Code of Conduct,
please report it privately to **mashware@gmail.com**.

All reports are handled confidentially. Maintainers are obligated to
respect the privacy and safety of the reporter.

## Enforcement

Maintainers will follow the enforcement guidelines defined in
section 4 of the Contributor Covenant v2.1:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines

These range from a private written warning for first incidents, up to
a permanent ban from the project's spaces for sustained or severe
violations.
